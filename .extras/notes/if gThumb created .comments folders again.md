# Stop gThumb from creating `.comments` folders

gThumb may create hidden `.comments` directories beside images or videos. These directories are associated with gThumb's **Comments and Tags** metadata extension.

## Disable the behavior

1. Open **gThumb**.
2. Open the main menu (`≡`).
3. Select **Preferences**.
4. Open the **Extensions** section.
5. Disable **Comments and Tags**.
